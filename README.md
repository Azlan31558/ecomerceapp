**Flutter E-Commerce App**

A modern and responsive ***Flutter E-Commerce Application** built with Flutter and Dart. This project demonstrates a complete shopping experience with product browsing, categories, search, wishlist, cart, checkout, profile management, notifications, and more.

## Features

*  Modern E-Commerce UI
*  Home screen with featured products
*  Special offers and sale products
*  New arrivals section
*  Product categories
*  Product search
*  Wishlist functionality
*  Shopping cart
*  Checkout screen
*  User profile
*  Edit profile
*  Notifications
*  Settings
*  Product details
*  Responsive Flutter UI
*  Centralized custom app theme
*  Smooth navigation between screens
 

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Material Design**
* **Dart OOP**
* **Responsive UI**
